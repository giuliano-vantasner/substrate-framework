# Review of CM6 Terminal Qualification

CM6 claims that a literal scan proves barrier machinery is confined to CM1 and
CM7, B-side magnitudes are neutral and uncapped, and an empirical data gate is
closed. The review requires exact matcher, AST, evasion, collision, file-scope,
input-provenance, predicate, dependency, and consumer ledgers.

## Independence

The independent route imports no P120 implementation. It implements a fresh
line matcher and clamp detector, parses the whole phase-31 Python surface,
classifies executable identifiers, and constructs separate tag, construction,
Unicode, algebra, prose, clamp, empirical, import, and partition probes.

The primary route's first run failed after thirty-eight checks because it
guessed CM3's filename rather than resolving the inventory. That fixture defect
is preserved and repaired with the pinned queue path; no scientific predicate
or tolerance was weakened.

## Verification Status

The surviving result is exact finite syntactic evidence, not a new scientific
claim. Forty-seven primary and thirty-five independent checks pin source bytes,
recover source constants, reproduce all twenty predicates, compare AST
locations, and test false negatives, false positives, scope, and provenance.

CM6 uses no numerical integration and triggers no NumPy compatibility event.
No numeric or simulation verdict is inflated into exact evidence.

## Sensitivity and Counterexamples

The scanner detects the selected literal fixtures and is case-insensitive for
tokens, but its tag is case-sensitive and line-wide. A marker inside string
data hides executable syntax. Concatenation, `getattr`, Unicode punctuation,
equivalent algebra, imports, and external data evade it. Comments, docstrings,
negation, and `tau_evolution` create false positives.

CM3 is a pinned decisive scope counterexample: its own source labels it B-side,
but CM6 omits it. CM3 contains raw `U_e` and `Gamow` prose, so literal inclusion
fails, while its executable AST contains no `U_e` identifier. Across all
phase-31 Python files, executable `U_e` occurs in CM1 and CM7 only; this remains
syntactic rather than physical evidence.

Whitespace variants, clipping, branches, helpers, bounded nonlinearities,
denominators, and tables evade the clamp scan. Numeric and imported comparison
targets evade the empirical list. Benign capacity names and unused empirical
comments show the opposite collision direction.
