# NA1 Qualified Review

## Decision

NA1 is qualified through C-HOL-001, C-NAG-001, and C-REP-002. Its exact
fundamental center controls, symbolic noncommuting matrix-function difference,
local BCH coefficient, and commuting control survive only within the corrected

## Corrected Positive Object

The path equation paired with C-NAG-001 gives later-left chronology and an
endpoint-factor gauge law. Only a declared closed path transforms by
conjugation, so conjugacy class, spectrum, determinant, and typed traces—not
the transporter matrix itself—supply invariant data. Reverse paths invert,
commuting segments collapse, and noncommuting segment order changes the
matrix. The same SU2 center is representation dependent.

## Retained and Rejected Content

and its `su2_z` helper has the opposite orientation away from center angles.
Its final set comparison equates assigned values without common objects or
maps. No physical weak connection, Aharonov--Bohm flux geometry, matter
carrier, detector, common Berry/Wilson/parity object, or substrate mechanism
follows.
