## Sensitivity and Counterexamples

the pin preserves coefficient rank but makes the prior branch inconsistent.

while mutations of all three non-gravity rows leave OD3.5 green. Re-floating

inverse-gravity baseline destroys the first constant log slope; changing b0
changes the allegedly numeric folded factor; and reciprocal-coordinate
rescaling moves the numeric fixed point.
