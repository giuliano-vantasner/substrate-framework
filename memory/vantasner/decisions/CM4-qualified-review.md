# Review of CM4 Terminal Qualification

## Claim Under Review

CM4 claims positive derivatives of a declared response against N and A-squared
and presents an array-order predicate as a falsifiable CMNC signature. The
review requires the exact continuous and discrete ledger, accepted dependency
closure, source-predicate stress tests, mechanism specificity, and novelty
decision.

The review reads v0.97.0, C-RG-002, C-SPN-002, C-CMP-001, their canonical
modules and immutable audits, P118's frozen contract, all attempts, both
verifiers, and every P118 evidence record. CM4 is pinned at SHA-256
`984b5a1495c0d17095b127cc79eceb9625592051b0e5ab099bc66683b418c019`;

material, magnitude, yield, heat, and observation readings remain outside the
accepted surface.

## Independence

The independent route imports no P118 implementation and defines the response
afresh. It derives derivatives, integer differences, elasticities, limits,
curvature, scale covariance, the full C-RG composition, and quotient slopes.
It independently reads the accepted registry to close nonduplication.

One independent nonduplication probe failed because it searched for a shortened
registry assignment rather than the accepted statement's full intermediate

to the exact fresh symbolic composition.

## Verification Status

The surviving conditional surface is symbolic verified but earns no new
claim. Forty primary checks and twenty-nine independent checks establish the
exact ledger, mutations, false-positive report structures, identifiability,
and accepted-claim match. The source's selected substitutions and arrays are
regression evidence only.

No canonical code changes, so unchanged package suites are not rerun as

sampled integration occurs and no NumPy compatibility event exists.

## Sensitivity and Counterexamples

Exponent sign, N power, loading power, omitted N, forward-difference sign, and
unit step are load bearing. Reversed controls yield negative quotient slopes
while passing the source response-order check. Duplicate controls make the
quotient undefined, unequal array lengths define no paired derivative, and the
A2 branch accepts reversed or nonpositive coordinates.

An unrelated affine response and infinitely many positive-exponent monomial
families share both headline signs. A nonmonotone response passes on a selected
rising limb. A one-ulp rise passes without an uncertainty threshold. Zero
interaction gives zero physical rate, and a free normalization fits any
positive response magnitude.

## Framework Compatibility

C-RG-002 already owns the conditional inverse-A-squared barrier, dimensions,
held-fixed sensitivity, identifiability, and physical ceiling. C-SPN-002 owns
the normalized finite-vector coefficient and explicitly withholds rate
semantics. C-CMP-001 owns the declared composite-factor and non-rate dimension

The response dimension resides entirely in the free normalization; its sign
does not type the observable. N is a count unless a continuous extension is
declared. A2 has no material control meaning without the C-RG constitutive map
and calibration. No accepted invariant is changed.
