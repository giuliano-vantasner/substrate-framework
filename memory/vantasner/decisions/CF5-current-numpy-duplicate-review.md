# CF5 Current-NumPy Duplicate Review

## Source Unit Under Review

CF5 proposes a consistency bridge from the conditional smooth Abelian-Higgs
vortex to an ideal uniform fixed-area tube through an effective core area and
an order-one penetration-area ratio.

## Sourced Inputs

The review read v0.127.0, C-VTX-001/002, C-FLX-001, canonical vortex, tube,
numeric, and compatibility modules, P026/P029 evidence, hash-pinned CF5 and its
dossier, the migration disposition, and local memory. CF5 and the dossier match
source baseline `6d1f4e0`; unrelated predecessor worktree changes are excluded.

## Compatibility and Reproduction

Native CF5 stops before its first predicate only because NumPy 2.5.1 removed
`np.trapz`. The event is version-only and does not reject a scientific
candidate. An isolated alias backed only by `np.trapezoid` leaves the source
bytes and equations unchanged and passes all six predicates. The four-node
graph uses the same isolated treatment only for CF1 and CF5.

## Scientific Closure

The BVP, flux, and inverse lengths are duplicate C-VTX-001/002 evidence. The
fixed-area slope and `A_eff=Phi^2/(2*sigma)` reconstruction are already in
C-FLX-001. Back-substitution returns every supplied positive tension, so it is
an identity rather than a prediction.

The penetration-area ratio simplifies to
`2*pi^2*n^2*v^2/sigma`; it contains no independent profile geometry and the
gauge coupling cancels. The `[0.1,100]` window admits a factor 1000 in tension,
including 0.1, 10, and 40 times the demo tension. Vector-versus-scalar lengths
and a free core-area convention add further unselected factors. A profile
moment would be new input, and CF5 computes none.
