## Implementation and Oracle Plan

SymPy is the primary oracle because all load-bearing potential derivatives,
eliminations, substitutions, and deformations are exact. The independent route
derives the same relation from coefficient algebra without importing GC1. The
profile substitution is regression coverage, not independent evidence.
Alternative normalization, nonlinear and independent coupling maps, a sextic
potential deformation, and translated fixed-depth wells test universality.

No numerical spectral run is justified from the queue excerpt alone. If source
inspection reveals a genuine bound-state threshold, its operator, domain,
boundary data, discretization, tolerances, refinement, error norm, and
independent method must be frozen in a proposal revision before evaluation.
Compatibility preflight scans direct, imported, dynamic, and eager legacy
NumPy access. Mutable code uses `np.trapezoid` or the shared helper; immutable
version-only events are alias evidence and never scientific failures.
