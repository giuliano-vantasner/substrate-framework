## Invariants, Conventions, and Allowed Imports

Let `Omega>=0` and `omega>0` be exact quantities in one declared unit. Then
`n=floor(Omega/omega)` and `r=Omega-n*omega` uniquely satisfy integer `n>=0`,
`Omega=n*omega+r`, and `0<=r<omega`. For `n>=1`, the plateau is
`Omega/(n+1)<omega<=Omega/n`; quotient zero occurs when `omega>Omega`.

The mean `Omega/n` exists only for `n>=1` and equals `omega+r/n`, so its exact
nonnegative error from `omega` is `r/n<omega/n`. Any asymptotic claim must state
which scale is fixed. The quotient is a weakly nonincreasing staircase in the
divisor, not a differentiable or strictly decreasing response.

Integers, rationals, or exact decimal construction govern threshold-adjacent
floors. P090 and P110 may be used only as historical exact and nonduplication
evidence. PN2 is qualified evidence with no accepted physical subdivision
claim. Pending GB5 grants no authority. Exact arithmetic, SymPy, and declared
countermodels are allowed; no empirical energy or material value is an input.

The source has no numerical-integration hint. Canonical sampled integration,
if unexpectedly required, uses `trapezoid_integral`; mutable current scripts
use `np.trapezoid`. An immutable source that aborts only on `np.trapz` receives
an alias-only recorded replay before adjudication, and that version event is
not a scientific failure.

uniqueness, inequalities, plateaus, one-sided jumps, scale covariance, error
bounds, and declared limits. A fresh independent route uses scaled integer
`divmod` and cross-multiplication without importing a campaign helper.

versus ceiling, omitted remainder, reversed bracket, strict versus weak

still audits GB2's own predicates. A canonical module is added only if a new
