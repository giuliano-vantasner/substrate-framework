## Implementation and Oracle Plan

SymPy will derive tractable opened overlap kernels and exact limits. General
translation covariance follows by change of variables, while singular-value
convergence uses an explicit matrix norm and Weyl-type bound independently
rederived for the finite matrix. Countermodels change amplitudes, widths,
couplings, offsets, field labels, solution multiplicity, charge assignments,
and interaction incidence. A numerical source rerun is reproduction only when
the exact object already fixes its output.

Any genuinely unresolved quadrature or eigensystem obligation will state the
equation, Cartesian or radial measure, domain, normalization, precision, grid,
integration rule, solver status, tolerance, refinement, stopping rule, and
scale-relative error norm. Compatibility preflight scans direct, imported,
dynamic, and eager legacy NumPy access before the native run. Pending GC6 is
replayed only as a separately reviewable consumer and grants no authority.
