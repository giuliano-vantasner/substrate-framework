## Implementation and Oracle Plan

SymPy exact matrices and symbolic local jets are the primary oracle for
covariance, commutators, curvature, projector action, and trace identities.
A fresh route will use finite matrix transformations or independent component
expansion without a new canonical helper. Action claims require direct
variation and dimensions; numeric simulation is unjustified unless the source
contains a genuinely evolved claim not closed exactly.

Mutations change generator normalization, connection sign, coupling placement,
noncommutative ordering, derivative terms, projector factor, curvature
coefficient, action normalization, source conservation, or matter content.
Countermodels retain gauge algebra while changing anomaly cancellation, mass,
states, currents, and detector semantics.

Mutable code must use exact algebra, `trapezoid_integral`, or `np.trapezoid`
and contain no executable legacy access. P150 graph evidence says W7 has no
legacy reference. Any contrary immutable version-only abort would be isolated
through the current compatibility workflow and would not reject a scientific
candidate.
