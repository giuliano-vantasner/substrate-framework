# P152 B1 Berry Connection Audit

## Question and Positive Deliverable

P152 must deliver an exact importable classification of B1's projective base
loop, chosen lift, section, local Berry one-form, endpoint transition, and
gauge-invariant holonomy. The positive object must separate a local gauge
representative from a closed-loop phase and from a physical vector potential.
If accepted APIs already govern the exact surface, a complete qualified
disposition rather than a duplicate claim remains a positive framework result.

## Implementation and Oracle Plan

SymPy exact vectors, projectors, endpoint phases, and one-form transformations
are the primary oracle. A fresh route will derive the transition-corrected
holonomy from projectors or real lifts without importing any new canonical
helper. A finite exact theorem is preferred over numeric integration; any B1
quadrature is regression coverage and must use `np.trapezoid` in mutable code.

Mutations change normalization, phase sign, path orientation, endpoint
transition, periodicity, half versus integer strength, and replace a nontrivial
projective loop by a fixed ray. Countermodels keep the same minus-one scalar
while changing domain, lift, electromagnetic dictionary, material, or physical
state. Direct, imported, dynamic, and eager-fallback NumPy shapes are audited.
Immutable B1's known eager `getattr` legacy default receives an explicit
alias-only replay backed by `np.trapezoid`; the native version abort is not a
scientific rejection. Mutable code may use exact algebra, the canonical helper,
or `np.trapezoid`, never executable `np.trapz`.
