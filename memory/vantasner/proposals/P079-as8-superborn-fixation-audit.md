continuous neutral point, declared probability and selection domains, a

## Implementation and Oracle Plan

SymPy exact algebra is the strongest oracle for the removable limit, series,
ODE residual, boundary solve, derivatives, complement symmetry, intensity
parameterization, and rescaling laws. Inequality arguments will be stated from
the exact exponential representation rather than inferred from samples. A new
pure module is allowed only if the resulting fixation and normalization object
is nonduplicate and reusable. The independent route will rebuild every
expression without that module. Mutations flip `S`, change an absorbing
boundary, change the generator coefficient, rescale both intensities, omit the
compensating coefficient, fix total normalization, and remove every pending
physical dependency. No numerical integration is required; neither
`np.trapz` nor `np.trapezoid` will appear.
