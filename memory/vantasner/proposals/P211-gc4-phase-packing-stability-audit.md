# P211 GC4 Phase-Packing and Stability Audit

## Question and Positive Deliverable

P211 must derive the actual interaction object for GC4's declared localized
complex trial fields, prove the strongest exact scalar-phase capacity theorem,
and determine whether either result supplies a finite-separation stable
coexistence or selects exactly three. The positive deliverable is an importable
phase-capacity object if novel, an energy/force/stability type ledger,
claim-level predicate review, and a terminal GC4 disposition; a refuted
stability headline alone is not completion.

## Base Release and Provenance

The accepted base is v0.152.0 at clean framework commit `f04062b`, with 192
accepted claims, 14 pending units, and 191 qualified units. GC4 is pinned at
source commit `6d1f4e0`, SHA-256 `32924005...f465bb`, and 26,753 bytes. Its
accepted terminal inputs are E1, EM6, FG2, FG4, GC1, GC2, GC3, MH2, WM7, and
WM10 at their registered ceilings; pending GC5 is a nonauthoritative cycle
edge. The predecessor worktree is dirty outside the pinned source file, so
newer prose and unrelated edits are excluded.

The generated queue exposes eight static check sites, one assertion, and
truncated claims about phase-dependent pair energy, attraction and repulsion,
exponential decay, coexistence stability, and a count of three. The exact
functional, profiles, grids, phase samples, tolerances, fits, count argument,
remaining predicates, and native output remain unopened through the freeze.

## Invariants, Conventions, and Allowed Imports

C-QBL-001 provides one conditional quartic stationary profile and explicitly
no nonlinear stability or forced ontology. C-QBL-003 has a negative
unconstrained scalar Hessian mode and no fixed-charge stability theorem.
C-OVL-001 and C-OVL-002 provide conditional overlaps and translated external
wells, not a common nonlinear multisoliton. C-MIX-003 provides common-phase
matrix algebra, not stable condensates or a selected count. Energy, force,
equilibrium, spectral stability, and nonlinear stability remain distinct
types. Strict pairwise cosine negativity, weak nonpositivity, sparse graphs,
and vector-valued internal orientations remain distinct packing problems.

## Selection Criteria and Blinding

Selection prioritizes exact functional fidelity, correct typing of energy and
stability, strict-versus-weak inequalities, assumption economy, graph and
dimension dependence, correct limits, novelty, and terminal closure. No source
numeric value or fit may choose the theorem. Source details open only after the
contract, formula freeze, provenance record, memory and repository validation,
and clean freeze commit.

## Proposed Claim Delta

P211 reserves provisional C-PHS-001 for the minimum novel exact scalar-circle
phase-capacity theorem and its strictness and nonselection caveats. It will
depend on no physical claim unless opened source analysis proves a necessary
accepted dependency. The identifier was absent from registry, campaign, and
memory searches at freeze. Pair-energy formulas may remain campaign evidence
if they are model-specific or already composed from accepted profiles.

## Implementation and Oracle Plan

SymPy will independently expand the opened functional, derive tractable sech
integrals and asymptotics, and prove phase identities. The scalar-circle cap
will receive a separate elementary ordered-gap proof and finite witnesses;
floating-point sampling cannot verify it. Mutations change strict `<0` to
`<=0`, remove graph edges, change kernel signs, and enlarge the internal
orientation space. A collective separation direction tests whether repulsion
creates a finite minimum or merely drives dispersion. No stability verdict is
allowed without a common field equation, constraints, boundary data, and a
spectral, Lyapunov, or evolution oracle.

Any unresolved numeric obligation will state precision, domain, grid,
integration rule, error norm, status gate, mesh/domain/fit-window refinement,
and independent asymptotic route. Compatibility preflight scans direct,
imported, dynamic, and eager legacy NumPy access. Mutable code uses
`np.trapezoid` or `trapezoid_integral`; an immutable version-only abort receives
an alias-only replay and never counts as a failed scientific candidate.

## Review and Promotion Plan

Every GC4 predicate receives an individual verdict. A novel phase theorem
requires canonical code and tests, exact primary and independent proofs,
claim-level review, impact analysis, registry and release update, generated
documentation, synchronized memory, and one full promotion gate. If no claim
or API changes, GC4 still requires a qualified or refuted disposition with
materialized evidence and a record-sensitive closeout.

## Done Gate

P211 closes only when the exact interaction and capacity objects, stability and
count ceilings, countermodels, source-predicate adjudication, authority graph,
compatibility audit, source disposition, generated state, and durable memory
agree with an empty debt ledger. A converged pair-energy plot or an upper bound
of three is not the requested stable three-object mechanism.
