# P197 MD2 Phase Variance Audit

## Question and Positive Deliverable

P197 must deliver the strongest exact importable scalar-mode variance theorem
available from an explicitly declared oscillator quantization, vacuum state,
continuum measure, and cutoff. It must also state exactly what the factorization
of a fixed sum into mode count and arithmetic mean does and does not establish.
A refutation of MD2's physical headline is evidence, not completion.

## Invariants, Conventions, and Allowed Imports

The accepted medium remains classical and one-dimensional. P197 may use
C-DOS-001's declared-d continuum measure and gapped dispersion, but canonical
quantization, vacuum state, stiffness normalization, dimension, branch count,
volume, and UV cutoff must be stated separately. AS6 and AS7 supply no accepted
beta value or granularity. A fixed finite set obeys total equals count times
arithmetic mean; changing the set can change the total and is a different
operation. Mutable numeric probes use `numpy.trapezoid` or the shared helper.

## Selection Criteria and Blinding

Selection prioritizes typed premise separation, framework fit, exact
normalization, dimensional consistency, limits, mutation sensitivity,
fixed-set versus set-growth honesty, nonduplication, and downstream utility.
Numerical closeness cannot select a concept.

claimed; all structural criteria and planned mutations are frozen before any

## Implementation and Oracle Plan

The reusable API will live under `src/substrate_framework/` and expose the
per-mode oscillator ground-state variance, exact d3 continuum integral, J(X)
kernel, and fixed-set sum/mean ledger without running simulations on import.
SymPy will verify normalization, integration, dimensions, limits, derivatives,
and mutations. An independent raw derivation will avoid the canonical API.
Finite spectra and set-growth counterexamples will probe the factorization
ceiling. Any sampled regression will use `numpy.trapezoid`, declare its grid
and error, and remain numerical evidence only.

Compatibility preflight scans direct, imported, and dynamic legacy trapezoid
access, including eager nested defaults. Mutable code is repaired to the
current API; immutable source receives an alias-only replay if needed, and a
version event never counts as scientific rejection. Source graph replay will
pin lexical check sites, runtime checks, assertion nodes, dependencies, and
reverse consumers separately.
