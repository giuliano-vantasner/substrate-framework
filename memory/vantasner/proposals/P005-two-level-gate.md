# P005 Normalized Two-Level Gate

## Question and Positive Deliverable
This campaign derives the exact gate generated by the normalized upper-state occupation of a two-level partition function. The positive claim `C-TH-001` states that for real dimensionless splitting `x`, `P=e^-x/(1+e^-x)=1/(1+e^x)`, its Bernoulli variance is `P(1-P)=sech^2(x/2)/4`, and `W=2P(1-P)=sech^2(x/2)/2`. The gate is even, has global maximum `1/2` only at `x=0`, decreases strictly with `|x|`, and vanishes at both infinities.

Conditionally, a single-event definition `W=2P(1-P)` and a macroscopic shape `A sech^2(x/2)` share one exact function with `A sech^2=2A W`. The identity fixes shape and relative factor; it does not derive the independent amplitude `A`, a microscopic ionization law, or a device-scale rate.

## Base Release and Provenance
The accepted base is `v0.4.0` at framework commit `25aec1f`. The new thermal utility is independent of the accepted sine-Gordon and optical claims.

The hash-pinned source unit is T1G at `merged-framework/bridges/phase-1/bridge_T1G_thermal_gate.py`, SHA-256 `afa71de3a9b34078f866f3444561a7c6e90b367358103c210b9d513281c06d21`. It is pending in the migration queue. Its imported cross-program interpretations are inputs to the conditional mapping, not automatically accepted derivations.

## Invariants, Conventions, and Allowed Imports
The variable `x` is real and dimensionless; physical substitution `x=Delta/(k_B T)` is permitted only with `T>0`. The normalized partition function is `Z=1+exp(-x)` and its upper-state occupation is `P=exp(-x)/Z`. The factor 2 in `W`, the hyperbolic half-angle, and the distinction between normalized occupation and raw Boltzmann factor are load-bearing.

The campaign may conditionally relate matching shapes but cannot infer the macroscopic amplitude, causal mechanism, or an average over an unspecified ensemble.

## Selection Criteria and Blinding
The frozen order is exact normalized construction, absence of fitted parameters, global bounds and limits, independent partition-function meaning, mutation sensitivity, then API simplicity. Candidate A is selected for the exact closed identity. Candidate B is the independent review route. Candidate C supplies global qualitative checks but is not used to select a fitted shape.

## Implementation and Oracle Plan
A pure `src/substrate_framework/thermal.py` module will expose normalized occupation, variance, and symmetric gate APIs with real numeric domain checks. Package tests will cover exact identities and invalid complex input.

The main verifier will prove the exponential and sech forms, variance/susceptibility identity, evenness, exact derivative sign form, global maximum by a nonnegative-square identity, limits, conditional amplitude relation, and coefficient/normalizer/half-angle mutations. The independent review will derive state moments directly from `Z` without importing the new APIs and will reject both the raw Boltzmann factor and wrong half-angle.
