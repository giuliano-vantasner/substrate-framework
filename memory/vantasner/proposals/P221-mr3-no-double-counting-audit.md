# P221 MR3 No-Double-Counting Audit

## Question and Positive Deliverable

P221 must decide whether MR3 contains a distinct theorem about component
energies on one shared configuration beyond C-VAR-002 and C-GSK-001, then give
MR3 a terminal disposition. The positive object is an exact typed functional,
bound, comparator, and dependency ledger; merely rejecting the source's
physical double-counting story is not completion.

## Base Release and Provenance

The base is v0.158.0 at clean commit `097d184`, with 201 accepted claims and
four pending units. MR3 is pinned at substrate commit `6d1f4e0`, SHA-256
`c5eaab...e7eddc`, 20,506 bytes, and 380 lines; its tracked path is clean while
unrelated source worktree changes remain excluded. The generated queue exposes
six checks, three assertions, symbolic and numeric oracles, the corrected and
classical supplied values, the false both-near predicate, and the one-functional
headline.

## Invariants, Conventions, and Allowed Imports

C-VAR-002 already owns the exact finite-family joint-infimum theorem and common
minimizer criterion. C-GSK-001 owns one declared conditional nonnegative radial
functional but supplies no physical coefficients, minimizer, or state. C-BPS
bounds do not imply attainment; C-SK-001 does not allocate a physical mass to
sectors. Terminal MR1 and MR2 are evidence only at their accepted owners, and
pending MR4 through MR6 cannot support MR3.

## Selection Criteria and Blinding

Common-admissible-set typing, novelty, dependency closure, bound-versus-energy
logic, component-value-versus-component-infimum logic, mutation sensitivity,
and physical state closure rank before numerical proximity. Queue-exposed values
cannot be blinded; every remaining equation, solver detail, predicate, output,
and consumer conclusion remains unopened through the validated freeze commit.

## Proposed Claim Delta

The committed freeze proposed no identifier. After source inspection, P221
provisionally reserves C-VAR-003 for the mixed variational interaction
`inf(A+P+Q)+inf(A)-inf(A+P)-inf(A+Q)`. C-VAR-002 does not fix this four-infimum
mixed difference. C-VAR-003 will prove its pointwise cancellation, both signs
and arbitrary real reach with nonnegative coercive quadratics, a common-
minimizer sufficient condition, and failure of the converse. It imports no
physical model or parameter.

## Implementation and Oracle Plan

SymPy is the strongest oracle for composition, lower-bound, slack, and ratio
identities. If source numerics express behavior not fixed by exact algebra, they
must declare solver, domain, mesh, tolerance, status, error, and refinement;
otherwise they remain regression or supplied-profile evidence. Primary checks
will import canonical variational and generalized-radial APIs, while the fresh
reviewer will derive the logic without source or canonical physics imports.
The graph will reuse hash-identical executions when available. MR3 already uses
current SciPy `trapezoid`; mutable new NumPy work uses `np.trapezoid`, and any
immutable legacy event remains compatibility provenance only.
