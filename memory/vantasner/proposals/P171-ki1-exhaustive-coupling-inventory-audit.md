# P171 KI1 Exhaustive Coupling Inventory Audit

## Question and Positive Deliverable

P171 must determine whether KI1 supplies a complete, reproducible, and
mutation-sensitive negative inventory for numeric generalized-Skyrme coupling
assignments in the pinned predecessor tree. The positive deliverable is a
baseline-scoped claim-level adjudication that defines the searched universe,
distinguishes model-specific assignments from generic token mentions, injects
load-bearing witnesses, closes accepted dependencies and consumers, and gives
KI1 a durable disposition without turning corpus absence into physical
uniqueness or non-identifiability.

## Invariants, Conventions, and Allowed Imports

A negative corpus statement is meaningful only at the pinned commit and under
an explicit universe, inclusion policy, syntax/context definition, and search
implementation. `git ls-files` describes tracked paths, not untracked files,
ignored files, external data, other commits, or all possible sources. Binary,
generated, vendor, campaign, dossier, and source categories must be typed
rather than silently merged.

Generic `lambda`, `mu`, and `epsilon` occur across unrelated mathematics and
physics. A model-specific assignment requires declared generalized-Skyrme
context and a semantic numeric value, relation, or derivation. Symbol creation,
formula participation, prose saying “unvalued,” and a numeric token elsewhere
in a file do not establish an assignment. Conversely, plausible scientific
notation, constructors, dictionaries, configuration rows, scientific notation,
and alternative coupling names must not evade the oracle.

C-BPS-001 declares positive free `lambda` and `mu` and selects no value or
physical action. C-BPS-002 adds only conditional sector attainment, and
C-BPS-003 keeps `epsilon`, correction coefficients, and remainders explicit.
Accepted E1/E2 geometry and S4/WZ4 vector/EFT algebra supply no parameter
values for the BPS energy. No physical baryon, nucleus, yield, empirical fit,
or substrate premise is allowed.

Compatibility is scientifically neutral. Mutable P171 numeric integration, if
any, uses `np.trapezoid` or `trapezoid_integral`; executable syntax is audited
for direct, imported, dynamic, and eager legacy access. An immutable missing-
name stop is preserved and replayed only through an isolated alias backed by
`np.trapezoid`, never counted as a search-concept failure.

## Selection Criteria and Blinding

Selection is ordered by pinned-universe completeness and reproducibility,
model context and assignment semantics, injected-witness and pattern-mutation
sensitivity, accepted-claim dependency fit, assumption and API economy,
consumers, nonduplication, and governance. A zero-hit tally cannot select a
candidate by itself. The source result, dependencies, and P107 ceiling are
already exposed; no fresh result or comparator blinding is claimed.

## Proposed Claim Delta

may qualify KI1 without becoming a scientific accepted claim. Candidate D is
expected to cover the scientific conclusion because the accepted BPS claims

Registry, campaign, package, and durable-memory searches found no accepted

## Implementation and Oracle Plan

The primary route will inventory KI1's imports, five lexical and runtime
checks, assertion nodes, git commands, root resolution, file inclusion and
exclusion policy, decoders, regexes, contexts, hits, self-exclusions, and
compatibility surface. Native execution will be reproduced from its declared
root and from a wrong working directory to determine whether path resolution is
load-bearing. Lexical sites, runtime executions, and assertions remain
separate inventories.

The strongest oracle is a deterministic source/tree audit, not SymPy or a
physics simulation. An independent route will enumerate the pinned tracked
universe from the recorded source inventory and classify exact assignment
forms without importing KI1. Temporary synthetic corpora will inject numeric
witnesses through direct assignment, SymPy construction, dictionaries,
configuration-like rows, scientific notation, and the alternative omega
symbols; each load-bearing pattern or file-policy mutation must change the
verdict. Generic unrelated tokens and prose are negative controls.

Accepted `bps_energy.py` and P107 evidence will be hash-audited and their
focused tests replayed proportionately. Full BPS derivations and numeric
profiles are not rerun because they do not test a source-absence statement.
The direct source graph and affected consumers will be replayed only after
their roles are typed. Any reusable audit machinery goes under
`src/substrate_framework/` with pure APIs and tests; campaign code may not be
promoted merely because its own five checks pass.

## Review and Promotion Plan

Every KI1 predicate receives an individual verdict. Terminal adjudication
requires literal and independent inventory evidence, explicit universe and
semantic definitions, witness and false-positive sensitivity, source and
dependency audits, consumers, graph, compatibility, nonduplication, and
materialized evidence paths. `Qualified` is appropriate only if a valid
baseline-scoped result survives; `duplicate_evidence` applies if the unit adds
only evidence for accepted claims; `out_of_scope` applies if it is purely
workflow provenance without a scientific candidate object.

A new claim additionally requires importable implementation and tests, impact
analysis, registry/release updates, generated documentation, and accepted
memory. Otherwise the accepted registry, release, and generated accepted state
remain unchanged. Validation and commit are separate processes. One terminal
workflow gate and the separately prescribed full suite run at the transaction
boundary; later record-only finalization receives only record-sensitive checks.

## Done Gate

P171 closes only when the baseline-scoped negative inventory is either
positively established with a sensitive oracle or replaced by a better
terminal disposition, every predicate and consumer is adjudicated, accepted
BPS scope remains intact, physical overreach is excluded, governed records
agree, and the debt ledger is empty. A zero-hit search, an honest incomplete
pattern battery, or a prose underdetermination statement alone is not
completion.

The better terminal disposition is `refuted`. KI1.2, latent KI1.3, and latent
KI1.4 are false at the governed baseline; KI1.5 is locally nonvacuous but
incomplete. Pending MK scripts refute corpus absence without becoming accepted
physics. C-BPS-001 through C-BPS-003, v0.127.0, and all accepted artifacts stay
unchanged.
