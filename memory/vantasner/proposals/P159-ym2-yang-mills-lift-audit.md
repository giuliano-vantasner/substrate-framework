# P159 YM2 Yang-Mills Lift Audit

## Question and Positive Deliverable

P159 must reproduce and independently adjudicate YM2's claimed lift from a
two-dimensional induced SU2 kernel to a 3+1-dimensional Yang--Mills sector. The
positive deliverable is either a distinct importable conditional operator
theorem, or an exact accepted composition showing that all supportable content
is already owned by the color, loop, and Riesz claims, together with a terminal
predicate-level YM2 disposition. Rejecting the lift prose alone is not
completion.

The generated queue exposes ten static checks, one assertion, symbolic and

Riesz kernels, and a claimed 3+1 lift. The predecessor worktree contains later

P158 already opened and executed YM2 through an isolated alias-only downstream
replay. P159 therefore makes no fresh source-blinding claim. That exposure is
provenance, not authority, and known source literals and conclusions are
excluded from selection.

## Invariants, Conventions, and Allowed Imports

C-NVP-001 owns a conditional massive complex-scalar SU2 one-loop theorem only
in flat Euclidean two-space and explicitly denies a dimensional lift.
C-NAG-001 owns finite local gauge covariance without an action coefficient or
propagator. C-KRN-001 and C-KRN-002 own fixed-input static scalar Riesz kernels
and prove that neither a power law nor an analytic dimension parameter selects
a physical dimension or gauge sector. C-MAX-001 supplies ordinary static
source-normalized branches, not a lift.

The campaign keeps a color trace metric, scalar static Green function,
quadratic gauge operator, full nonlinear action, Lorentzian propagator, and
physical sector separately typed. A three-dimensional static inverse has no
time operator, signature, gauge fixing, causal prescription, or source unless
those are supplied. Multiplying by `T(R)*delta_ab` changes none of them.

Allowed imports are C-NVP-001, C-NAG-001, C-KRN-001, C-KRN-002, C-MAX-001,
C-REP-002, their canonical modules, and exact operator, Fourier, tensor,
projector, and gauge-fixed algebra with every coefficient, dimension,
signature, source, gauge, and boundary premise explicit. YM2 and its dossier
remain hash-pinned noncanonical evidence.

## Selection Criteria and Blinding

Selection is ordered by accepted dependency closure; explicit operator domain,
dimension, signature, Fourier and boundary conventions; type separation among
color, static kernel, action, and propagator; gauge covariance or an honest
gauge-fixed linearization; coefficient and source freedom; correct limits;
mutation sensitivity; independent derivation; parameter economy; novelty;
consumer compatibility; and physical-scope honesty.

Genuine blinding is unavailable because P158 already exposed YM2. This
contract freezes the candidates and criteria before renewed targeted
inspection. Familiar `1/r`, trace-one-half, or successful tally values cannot
select a concept, define a threshold, or establish a dimensional lift.

## Proposed Claim Delta

The initial delta is empty. Candidate B is preferred if accepted claims
already contain the exact supportable surface. A new identifier may be
reserved only in a source-aware revision after a distinct, complete operator
theorem passes novelty and dependency review; unsupported lift prose cannot
justify framework expansion.

## Implementation and Oracle Plan

The primary route will hash, parse, reproduce, and map every YM2 predicate and
its assertion. Native execution is preserved. Because immutable YM2 contains
an eager legacy NumPy access, an isolated alias backed by `np.trapezoid` will
provide the unchanged scientific replay; the native compatibility abort is
not a failed candidate. Mutable code uses exact algebra, the canonical
`trapezoid_integral`, or `np.trapezoid`, never executable `np.trapz`.

SymPy exact tensor, exponent, projector, action-variation, and Green-operator
algebra fits the tractable obligations. NumPy or SciPy output is regression
evidence unless a genuinely numerical claim remains after exact reduction.
The independent route will not import any new P159 helper. Mutations change
spatial dimension, fractional power, representation index, kinetic
coefficient, gauge parameter, time operator, and source normalization. A
static scalar kernel must fail any oracle that claims a full Lorentzian
propagator without the missing structure.

The impact and nonduplication audits precede any package change. Source-graph
replay covers direct dependencies and semantic consumers, and campaign
verifiers pin durable snapshots rather than mutable current state.

## Review and Promotion Plan

Claim-level review will separately assess any new theorem and the YM2 source
disposition. Reusable logic is extracted only after novelty is established.
Promotion requires sensitive primary and independent oracles, exact
dependency closure, graph replay, impact analysis, generated registry and
memory agreement, one integrated terminal validation boundary, and an empty
ledger. Otherwise YM2 closes through an exact accepted composition with no
release change.

## Done Gate
