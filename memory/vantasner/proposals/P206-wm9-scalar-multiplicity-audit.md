## Implementation and Oracle Plan

SymPy is the strongest oracle for exact factorization, free-symbol sets,
substitution-equivalent parameterizations, ranks, and countermodels. The
primary route uses normalized-overlap APIs; an independent route constructs
raw integrals or abstract overlap matrices. Mutations rename and constrain
amplitudes, duplicate field labels, add independent couplings, rotate modes,
and vary mode and background counts independently.

Compatibility preflight scans direct, imported, and dynamic legacy NumPy
access. Mutable code uses `np.trapezoid` or the shared helper; immutable
version-name events are alias-only evidence and never scientific failures.
