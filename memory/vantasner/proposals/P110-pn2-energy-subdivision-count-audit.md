## Invariants, Conventions, and Allowed Imports

Let `Omega>0` and `omega>0` be exact energies expressed in one declared unit.
Then `n=floor(Omega/omega)` and `r=Omega-n*omega` uniquely satisfy integer
`n>=0` and `0<=r<omega`. For `n>=1`, a fixed quotient occurs exactly on
`Omega/(n+1)<omega<=Omega/n`; quotient zero occurs for `omega>Omega`. The
function is nonincreasing in `omega` and jumps at exact divisors.

MeV, eV, and meV conversions use exact decimal prefixes. Large integer counts
must be constructed through integers, rationals, or decimal strings, not a
binary floating value whose rounding can cross an exact floor boundary. If
either input has an interval or uncertainty, the honest output is the sharp
attainable integer set or bounds, not an unjustified single count.

C-SG-019 supplies only a normalization-dependent classical coefficient and
explicitly excludes quantum processes. FS4 terminally duplicates accepted
constant-offset derivative cancellation and supplies no energy partition.
P090 already established that Euclidean energy division is bookkeeping rather
than a formation theorem and added no claim. P110 promotes nothing unless a
distinct API and governed consumer survive this nonduplication gate.

The primary audit is exact and needs no sampled quadrature. If immutable PN2
aborts only because `np.trapz` is absent, an alias-only replay is recorded
before scientific adjudication. Mutable current-environment scripts use
`np.trapezoid`; canonical sampled work would use `trapezoid_integral`. A
compatibility event is not a scientific failure.
