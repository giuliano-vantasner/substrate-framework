# C-CF-001

## Statement
The accepted statement is reproduced exactly from the claim registry.

Model the SU(3) colour centre as the additive cyclic group ZMod 3 (the identification centre(SU(3)) = Z_3, generated by exp(2*pi*i/3)*I on the fundamental representation, is a declared input). Then the centre is cyclic with exactly three elements (card = 3) and its standard generator 1 has additive order exactly 3, in explicit contrast to the SU(2) centre Z_2 whose generator has order 2 (so the two centres are not isomorphic); the colour-triplet structure this supports is the declared interpretation. This is a conditional finite-group theorem on the declared model. It does not prove that the centre of SU(3) is Z_3, derive confinement or an area law, select a gauge group, or establish any physical string tension, quark, or hadron.
