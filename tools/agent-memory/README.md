# agent-memory CLI

This is a source snapshot of locally installed `agent-memory` version 0.1.0, originally installed from `finml-sage/agent-memory`. It contains the CLI program only; no existing memory entries, caches, or personal configuration are included.

Install from the repository root with:

```bash
python3 -m venv .venv
.venv/bin/pip install -e tools/agent-memory
```

The upstream package metadata declares the source MIT-licensed.
