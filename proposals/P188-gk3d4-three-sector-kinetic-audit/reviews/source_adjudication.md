# GK3D4 Source Adjudication

GK3D4 is qualified rather than accepted literally. Its hash-pinned SymPy
script exits cleanly with eleven checks, but those checks mix exact carrier
algebra and conditional arithmetic with hardcoded premises that do not build
the advertised common three-sector D4 construction.

The raw fundamental trace metrics survive. The Pauli-half and Gell-Mann-half
generators separately satisfy `Tr(T_a T_b)=delta_ab/2`, and the rational factor
is dimensionless. On the accepted `C^3 tensor C^2` product carrier, however,
spectator dimensions give color metric `I_8`, isospin metric `(3/2) I_3`, and
Abelian entry `6 y^2`; all cross-factor trace blocks vanish. Equal raw
fundamental indices therefore do not imply equal product-carrier loop weights.

The claimed D4 lift is not constructed. The source declares three sector
labels, generic trace symbols, a Dirac `4/3` factor, one common denominator,
zero affine boundaries, and a five-thirds trace ratio. It supplies no common
product matter field or action, determinant, bubble, seagull, spin statistics,
regulator, counterterm, masses, thresholds, factor matching, or anomaly solve.
Its advertised Abelian-limit guard contains no structure constants and does
not execute a non-Abelian-to-Abelian specialization.

The coupling-ratio formula survives only conditionally. For independent
factor families `Z_a=z_a+b_a L_a/(8 pi^2)`, the inverse-weight ratio between
factors `i,j` has exact residual

`b_i z_j-b_j z_i+b_i b_j (L_j-L_i)/(8 pi^2)`.

Only separately declared zero boundaries and a common logarithm reduce this
to `g_i^2/g_j^2=b_j/b_i`. Scale-matched C-VAC-004 retains each `z_a`, so neither
dimensional transmutation nor a shared medium removes the factorwise matching
data by itself.

The supplied fifteen-state table has exact trace coordinate `3/8`, as already
owned by C-REP-001. It equals a coupling coordinate only under a separately
common inverse-trace coefficient. Equal independent couplings give `1/2`, and
a paired Abelian rescaling with `rho=2` moves the coordinate to `3/23` while
preserving the conditional covariant law. C-ANO-001's three charge branches
also refute the claim that anomaly freedom uniquely forces the source table or
normalization.

Every source check is adjudicated in `evidence/check-adjudication.yaml`, and
the corrected result is independently rederived with 21 raw-SymPy checks.
GK3D4 maps C-LIE-001, C-REP-002, C-PGA-001, C-DIM-009, C-VAC-002,
C-VAC-003, C-VAC-004, C-REP-001, C-RGE-005, and C-ANO-001. Each claim remains
unchanged and is reviewed individually in `reviews/accepted_composition_review.md`.
The composition adds no distinct consumer semantics, so C-VAC-005 stays
reserved and unpromoted.

GK3D5 and GK3D6 remain separately pending. GK3D5 refers to the candidate
integrated-out excitation but does not reuse the three-sector ratio. GK3D6
directly repeats the universal ratio and three-eighths headline and may inherit
only the conditional common-boundary/common-log specialization. EL2 and HE5
gain no new three-sector or weak-angle authority transitively.

NumPy compatibility does not affect this decision. GK3D4, GK3D6, EL2, HE5,
and all mutable P188 scripts have no legacy trapezoidal surface. Immutable
GK3D5 selects its current-first lazy fallback under NumPy 2.5.1, where the
current API exists and the legacy API does not. No alias was injected and no
version event became a scientific failure.

No physical U(1), SU(2), or SU(3) sector, matter spectrum, total coupling,
unique Abelian normalization, weak angle, observable, or substrate mechanism
is accepted. No canonical code, test, claim, or release change is warranted.
