# CM4 Source Adjudication

CM4 is qualified through existing claims with no registry, release, or package
API delta. Its ten checks reproduce, and the displayed conditional derivatives
are exact, but neither the response nor the array predicate is a unique
physical signature.

For positive declared inputs, `R=nu*N*exp(-C/(A2*Theta))` is linear in a
continuous N extension. For integer counts its unit forward difference is the
same positive factor. Its A2 derivative is `R*C/(A2^2*Theta)>0`, its loading
limits are zero and `nu*N`, and its log elasticities against
`(N,A2,Theta,C,nu)` are `(1,x,x,-x,1)` with `x=C/(A2*Theta)`. The A2 curvature
is `R*x*(x-2)/A2^2`, so even the exact increasing response is not globally
convex.

This surface is already governed. C-RG-002 supplies the conditional inverse-A2
capillary barrier with dimensions, held-fixed conventions, identifiability,
and no-material/no-rate ceiling. C-CMP-001 supplies only a declared positive-
factor composition retaining a matrix-element dimension. C-SPN-002 supplies
normalized finite-vector ladder coefficients and explicitly states that their
squares are not rates. It does not derive CM4's N multiplier, symmetric state,
interaction, preparation, or the claim that N=1 is a two-body Rabi baseline.

The `clears_bar` implementation is not a derivative oracle. It checks only
whether response values rise in supplied array order. Reversed and duplicate N
controls pass; mismatched control and response lengths pass; the A2 branch can
pass reversed or nonpositive controls and bypass N>=2; and a one-ulp rise has
the same verdict as a resolved effect. An unrelated affine response or a
selected rising limb of a nonmonotone response also satisfies the sign rule.
No units, control spacing, estimator, error model, threshold, calibration,
uncertainty, or alternative hypothesis is represented.

Zero interaction removes any physical transition while leaving the formal
response coordinates available, and a free positive normalization fits any
selected magnitude. A positive derivative therefore establishes no collective
rate enhancement, material loading law, CMNC mechanism, discriminating
signature, falsifiability criterion, magnitude, yield, heat, or observation.

The exact ledger is retained as P118 audit evidence rather than inflated into
a new claim. Generalized exponents would add arbitrary parameters to
manufacture novelty, and the report predicate has no canonical consumer or
scientific semantics worth preserving as a framework API.
