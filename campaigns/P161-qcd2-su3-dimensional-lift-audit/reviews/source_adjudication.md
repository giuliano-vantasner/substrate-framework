# QCD2 source adjudication

QCD2 is qualified through existing accepted claims, not accepted wholesale.
Native execution aborts before its first check because Python eagerly evaluates
the legacy default in `getattr(np, "trapezoid", getattr(np, "trapz"))`. An
isolated compatibility alias backed by `np.trapezoid` reproduces all ten checks
and the terminal tally without editing the immutable source. This is a
version-only event and supplies no evidence for the lift headline.

The exact retained object is small. The standard fundamental SU3 trace metric
is accepted representation algebra. The scalar `d=3, s=1` Riesz inverse is the
conditional endpoint already owned by C-KRN-001. Their displayed tensor product
and radial derivative are exact once those inputs are independently supplied.
The fixed gamma, slope, finite-difference, and one-dimensional FFT values are
duplicate regressions rather than a map from the accepted two-dimensional loop
theorem to a four-dimensional gauge theory.

The central operator interpretation is reversed. QCD2 multiplies an already
inverted scalar Green kernel by `Tr(T_a T_b)`. If that trace metric instead
weights a quadratic kinetic kernel, fixed-source inversion produces the inverse
metric. For the fundamental SU3 normalization, QCD2's defined product is
`1/(8*pi*r)`, whereas the inverse of `(1/2) k^2` is `1/(2*pi*r)`. The two differ
by a factor of four. An exact representation-index mutation scales the two
objects oppositely. No declared source normalization repairs this because QCD2
contains no source or probe.

The source also provides no gauge action, action variation, time operator,
signature, gauge fixing, causal or boundary prescription, current, kinetic
coefficient, dimension-changing map, or nonlinear covariant fractional
operator. Its force label lacks a source-probe energy dictionary. Its Abelian
guard changes the trace factor manually while an `eps_self` switch remains
unused, so it changes conventions rather than taking a limit. Its FFT is a
one-dimensional `s=1/2` packet and does not test the claimed endpoint. The
docstring itself both calls the ceiling closed and states that the 3+1D
kinetic-term ceiling is not closed.

Decision: qualify QCD2 through C-LIE-003, C-NVP-002, C-KRN-001, and C-KRN-002
without a new claim, API, or release. Retain the trace metric, fixed-input scalar
Riesz kernel, defined tensor product, and exact derivative only under their
accepted types and ceilings. Do not promote a kinetic-kernel inversion,
Yang--Mills action, spacetime propagator, physical force, selected dimension or
exponent, physical color sector, dimensional lift, or substrate mechanism.

The primary, fresh independent, and frozen-graph routes pass 33, 21, and 25
checks; 53 focused accepted-API tests also pass. The graph replays all 135
predicates in thirteen hash-pinned units. Compatibility remains isolated from
science, no canonical code changes, and campaign debt is empty at the
no-release boundary.
