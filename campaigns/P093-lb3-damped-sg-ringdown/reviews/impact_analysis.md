# P093 impact analysis

P093 changes no accepted claim, release manifest, canonical symbol, or package
API. It terminally changes only LB3's migration disposition and materializes an
immutable audit campaign.

The source's surviving finite-window regressions map to accepted C-SG-016. Its
oscillator, field-mode, transient, and exact-periodicity interpretation ceilings
map to accepted C-DYN-001. C-SG-012 supplies the exact finite-control-volume
balance, while existing C-PDE-011 package machinery already contains the
reusable centered-damping solver, total-energy ledger, and exact-family
classifiers. None of those accepted statements changes.

Direct predecessor consumers are narrative bridge tables, the Phase-26 dossier,
the unified synthesis, and pending MC4's copied numerical machinery. There is no
direct executable engineering consumer of LB3's fitted values. They remain
outside accepted authority and require no framework code edit.

Replay scope is P093's primary and independent audits, the focused oscillator,
sine-Gordon, 1D solver, and numerics tests, the unchanged P091 primary exact
verifier, migration/governance validation, and one integrated workflow boundary
for the terminal disposition. Re-running P091's already accepted expensive PDE
campaign or adding another LB3 simulation would be validation ceremony because
P093 promotes no new numerical statement.

P093 introduces no direct call to `np.trapz` or `np.trapezoid`; sampled framework
integration remains behind `trapezoid_integral`.
