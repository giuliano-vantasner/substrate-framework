# T1Z2 Source Adjudication

T1Z2's ten checks reproduce, and its restricted arithmetic is exact. At
half-strength and integer linking number, `exp(i*pi*links)` is the accepted
integer parity character. Charges plus one and minus one are both odd and map
to minus one; even linking and zero charge map to plus one. The SU2 doublet
matrix for a two-pi rotation is exactly minus the identity.

Those facts do not establish the headline identity. Check Z6 reduces four
expressions to SymPy scalars and requires their Python set to have size one.
It never constructs the source domains, quotient maps into C2, generator
orientations, full functions, representation actions, or an intertwiner.
C4's nonfaithful sign character and two distinct C2-squared characters reproduce
the selected odd/even or minus-one values while differing in kernel and full
truth table. Typed labels make the source's scalar-set oracle fail immediately.

Check Z7 derives the SU2 rotation matrix but assigns the deck matrix with
`-I2 if host == "RP2" else I2`. Renaming the same host string to `RP^2` flips
the verdict, and an arbitrary non-space also returns `+I2`. The equality is
therefore a definition, not an independent topology or medium oracle. The
primary Finkelstein-Rubinstein result is conditional on a quantum kink field
theory and continuity and representation premises that T1Z2 does not supply.
Pending S2 grants none of them.

The bosonic guard changes disclination strength and charge instead of replacing
one character on fixed source inputs. Its difference is exact but cannot
validate object identity. The final boundary correctly insists that parity and
exchange are distinct, yet it assigns the exchange object as `i/4`. The cited
Lean theorem states the unit phase factor `exp(i/4)`; `i/4` has modulus one
quarter. The intended separation from minus one survives after correcting the
factor, but the source predicate itself validates the wrong value.

C-TOP-001 and C-CHR-001 already own every reusable exact surface and explicitly
withhold physical statistics and cross-domain identity. C-CHR-002 is not
promoted. T1Z2 is terminally qualified through those two claims; no common
representation, RP2 medium, kink or Skyrmion identity, exchange statistics,
physical fermion, or substrate mechanism is accepted.
