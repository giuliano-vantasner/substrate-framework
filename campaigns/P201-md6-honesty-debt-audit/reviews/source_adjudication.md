# MD6 Source Adjudication

MD6 reproduces all 40 native predicates with exit zero. Its exact finite
assignment matches, selected lexical absences, tag substrings, and conditional
symbolic identities are retained on the pinned MD1 through MD5 bytes.

The headline implications are not retained. The assignment scanner omits
ordinary Python value paths and the lexical scanner is neither an import graph
nor a pass-condition or provenance analysis. Prefix exemption does not prove a
tagged value inert: both actual MD4 tagged constants flow into checks, and the
WN6 comparator controls substantive thresholds. MD6 itself is outside the
scan, and the five sibling inputs are not internally hash checked.

The conditional algebra does not close the scientific ledger. Three spatial
dimensions, branch count, cell scale, volume, dispersion, and cutoff remain
declared premises; `A^2=S/M` is the assumption that cancels `M`; rho remains in
the branching magnitude; a population-dependent positive weight may reverse
the fixed-weight sign; and integer intensity has two adjacent modes. The
purported empty-ledger oracle is literal `True`, while the no-residual oracle
repeats only three identities rather than an inventory.

MD6 is therefore qualified, not accepted as a semantic firewall and not
refuted as finite source evidence. No claim, package API, release, or threshold
change is warranted. The accepted registry remains the authority for every
scientific surface named by the source.
