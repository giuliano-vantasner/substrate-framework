# P098 impact analysis

P098 changes no accepted scientific claim, canonical equation, symbol, API,
test implementation, release manifest, or generated documentation. It adds an
immutable numerical/source audit and terminal migration disposition for MC4.

The direct governed surfaces are `migration/dispositions.yaml`, the generated
`migration/source-claims.yaml`, the P098 campaign record, its durable proposal
memory, and the parent migration effort. The accepted dependency replay covers
the dimensional sine-Gordon, exact sine-Gordon, periodic PDE solver, and shared
numerics tests. No formal theorem or generated claim consumer changes.

The pinned predecessor narrative consumers retain broader claims, but they are
read-only evidence rather than framework consumers. Their hashes and exact
ceilings are recorded in `evidence/consumer-audit.yaml`. The source working
tree's modified synthesis files are explicitly excluded in favor of pinned
commit blobs.

Every new sampled trapezoidal diagnostic routes through
`substrate_framework.numerics.trapezoid_integral`; P098 introduces no direct
NumPy integration call. Because no canonical code changes, a new module or
test would be implementation duplication rather than extraction.
